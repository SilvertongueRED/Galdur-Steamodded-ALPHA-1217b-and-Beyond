## Galdur 1.2.1f (fork)

Removes the Steamodded upper version limit so Galdur loads on current Steamodded releases.

- `manifest.json`: dependency is now `Steamodded (>=1.0.0~ALPHA-1217b)` with no upper cap. Upstream added `(<=1.0.0~BETA-1814a)` in Sept 2026, which made Galdur show "Missing dependencies!" on newer Steamodded (for example 26.829.0).
- Version bumped from 1.2.1e to 1.2.1f.

Note: the upstream author capped the version because newer Steamodded builds stopped working with Galdur. This fork only lifts the cap; if you hit a crash on a new Steamodded build, please open an issue with the crash log.

Install: extract `Galdur-v1.2.1f.zip` into your Balatro `Mods` folder so you get `Mods/Galdur/manifest.json`.
